# Migrating to the v0.2 foundation

No migration is required for existing POC applications. Existing component constructors and fluent layout methods remain supported.

New code should:

1. Create an `ui.Environment` from `ui.DefaultEnvironment` and override theme, locale, media, and dependencies.
2. Start context-aware applications with `runtime.NewContext`.
3. Use semantic tokens and `Styled(ui.Style{...})` for reusable design-system components.
4. Install a `runtime/layout.Pipeline` with a platform `BatchMeasurer` when building a custom host.
5. Use `runtime/headless` and `runtime/layout` for deterministic tests.

Stateful reusable components should move process-level state into a stable mounted component:

```go
ui.Functional("counter", func(ctx ui.BuildContext) ui.Component {
    count := ui.UseState(ctx, 0)
    return ui.Button(strconv.Itoa(count.Get()), func() { count.Update(func(value int) int { return value + 1 }) })
})
```

Hook calls must remain unconditional and ordered. Effect callbacks receive a cancellable `context.Context` and may return cleanup. Legacy `ui.NewState` and the process-wide scheduler remain available during v0 migration.

Custom native hosts must migrate their mutation decoder to protocol v9. After the typed-style payload, decode one `uint8` computed-frame flag followed by four little-endian `float32` values (`x`, `y`, `width`, `height`) for every mutation. Hosts must also implement the version-1 native measurement request/result batch or report the capability as unavailable.

For controlled focus, associate inputs with `WithFocusNode` and forward native focus transitions as integer `NodeID` values to `Runtime.DispatchFocus`. Forward platform lifecycle events to `Runtime.SetLifecycle`; `Runtime.Stop` emits the final destroyed state.
